CastIQ Pro Durban Boat Intelligence V2

Files:
- app.py
- durban_boat_fishing_spots.csv
- ais_observations_sample.csv

Install:
pip install streamlit pandas requests folium streamlit-folium

Run:
streamlit run app.py

AIS/boat tracking input format:
vessel_name,timestamp,lat,lon,speed_knots

Use exported AIS/GPS data from reputable sources where you are allowed to use it, or manually log charter sightings / your own trips.
